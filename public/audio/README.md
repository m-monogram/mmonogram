# Музыка в 3D-студии

Конфигуратор ищет здесь файл `garage-theme.mp3` и, если он есть, показывает
в панели инструментов кнопку звука. Нет файла — кнопки нет, всё остальное
работает как работало.

## Что положить

Любой трек в mp3, на который у ателье есть права: собственная запись,
лицензия на коммерческое использование или трек из библиотеки вроде
Artlist / Epidemic Sound / Musicbed.

    public/audio/garage-theme.mp3

Коммерческие релизы (Snoop Dogg & The Doors — Riders On The Storm, любой
саундтрек NFS и прочее) сюда класть нельзя без письменной лицензии
правообладателя: сайт — публичная коммерческая площадка ателье, и претензия
прилетит не абстрактному «интернету», а компании.

## Каким должен быть файл

  - зацикливается без щелчка на стыке — трек играет по кругу
  - 128–192 kbps: на фоне сцены разницы не слышно, а вес втрое меньше
  - до 5 МБ: файл грузится отдельно от моделей и только по нажатию кнопки
  - выровнен по громкости, без резкого вступления

Громкость в плеере выставлена на 35% — трек должен быть фоном, а не
перекрикивать посетителя.
